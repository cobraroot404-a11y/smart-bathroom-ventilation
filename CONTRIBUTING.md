# Contributing

original work in this repository. See [LICENSE](LICENSE).

## Unsolicited contributions are not accepted

This repository does not accept unsolicited contributions. That includes
pull requests, patches, feature submissions, and code suggestions.
Submitting one does not transfer ownership and does not create any
obligation to review, accept, merge, license, or compensate for it - see
`LICENSE` section 5.

GitHub Issues and Discussions are disabled on this repository where the
platform allows it. Where GitHub does not provide a way to fully prevent
forking or pull requests on a public repository, that platform capability
existing does not constitute an invitation to use it, and no such
submission will be merged.

## Security concerns

If you identify a security concern, please avoid publishing exploit
details publicly. Use an owner-provided private contact method if one is
published; no contact address is published by default in this repository.

## Reuse

Reuse of any part of this project - copying, modifying, redistributing,
or building on it - requires prior written permission from Gautham. See
`LICENSE` for the full terms.
